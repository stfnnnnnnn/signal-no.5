# SIGNAL NO. 5

# Household, Health, Environmental, and Character Configuration Form

**Purpose**  
This questionnaire will be used to personalize the player's household, 8-bit game environment, characters, available resources, and typhoon preparedness scenarios. The information provided will influence the situations, decisions, and consequences encountered throughout the game.

**Privacy notice**  
This game does not require full names, exact addresses, birthdates, or medical records. Health-related questions are optional and will only be used to simulate relevant preparedness needs. Players may use their actual household configuration or generate a fictional household.

## Section V. Character and Visual Customization

### 25. Which household member would you like to play as?

After completing Section I, the system will generate a household roster based on the provided age and sex information. Select one household member to control during gameplay.

The game will use four reusable base character sprites:

| Base sprite | Intended visual template |
|---|---|
| **Boy** | Younger male-presenting characters |
| **Girl** | Younger female-presenting characters |
| **Mom** | Adult female-presenting characters |
| **Dad** | Adult male-presenting characters |

Household members may share the same base sprite but have different clothing colors, outfits, hairstyles, or other visual variations. The labels refer to visual templates rather than necessarily indicating family relationships.

**Character customization options**

- [ ] Use the automatically assigned appearance
- [ ] Customize clothing color
- [ ] Randomize clothing variation

### 26. Which Filipino household style would you prefer for your game environment?

Select one.

- [ ] Modern Filipino
- [ ] Traditional Filipino

| Theme | Visual description |
|---|---|
| **Modern Filipino** | Contemporary furniture, tiled flooring, modern household decorations, and neutral or cool color palettes. |
| **Traditional Filipino** | Wood-inspired textures, warmer color palettes, traditional furnishings, and Filipino architectural details. |

Both themes will use the same fixed floor-plan backbone, collision geometry, and interaction points. Only visual assets and decorative elements will change.

- Selected Modern Filipino or Traditional Filipino visual theme
